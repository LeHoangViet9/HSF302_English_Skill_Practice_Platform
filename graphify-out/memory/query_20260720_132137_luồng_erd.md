# Q: luồng ERD

## Answer

Auth ERD has users 1 to 0-or-1 student_users through student_users.user_id unique FK, and users 1 to many auth_tokens through auth_tokens.user_id. auth_tokens stores both SESSION and PASSWORD_RESET token types. Registration creates users then student_users. Forgot password creates PASSWORD_RESET auth_tokens; successful reset updates users.password_hash, marks token used, and revokes active tokens. Current login/logout does not write SESSION tokens because AuthSessionService is not wired.
